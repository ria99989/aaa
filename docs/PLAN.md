# 4週間計画(週20時間)

## 収益の組み立て(目標 月5万円)
| 柱 | 目標 | 内訳例 |
|---|---|---|
| 受託(画像処理/AI小案件) | 3万円 | 1.5万円×2件 |
| ココナラ等の定型メニュー | 1.5万円 | 5,000円×3件 |
| ツール販売(BOOTH等) | 0.5万円 | 1,000円×5本 |

## Week 1: 土台(実績ゼロの解消)
- [ ] GitHub 公開用に本リポジトリを整える。READMEにビフォー/アフター画像を載せる(6h)
- [ ] デモを2つ追加: ①OCR(領収書→CSV) ②物体検出/背景除去 の最小 PoC(8h)
- [ ] プロフィール文を作成、ココナラ・クラウドワークス・Lancers に登録(3h)
- [ ] 出品3メニューを公開(`GIGS.md`)(3h)

## Week 2: 営業開始
- [ ] 毎日、募集案件を5件チェックし、合う案件に提案(`PROPOSALS.md`)。目標: 週10提案(8h)
- [ ] 初回案件は価格を抑えて実績・レビューを取りにいく(2万円以下でも可)(8h)
- [ ] 2つ目のデモ公開、SNS/Zenn で記事1本(4h)

## Week 3: 納品と横展開
- [ ] 受注案件の納品。コードは汎用部分を切り出して再利用(12h)
- [ ] 提案継続(週10件)(4h)
- [ ] BOOTHに `imgbatch` をGUI/exe化(またはColabノート)して販売(4h)

## Week 4: 単価アップと継続化
- [ ] レビューを得たらメニュー価格を2〜3割上げる
- [ ] 継続案件(保守/月額)を打診
- [ ] 週次で数字を振り返り: 提案数→返信率→受注率→単価

## 目安の確率
提案10件あたり返信1〜3件、受注0〜1件。初月は提案数を確保することが最重要。
