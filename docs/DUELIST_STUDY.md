# デュエリスト研究ノート(meiy を参考にする)

## 進め方

1. **1 エージェント・1 マップから始める。** デュエリスト全員を一度に見ると、エージェント固有の動き(ジェットのダッシュ、レイズのサッチェル、ネオンのスプリントなど)と、どのエージェントでも共通する勝ち方が混ざってしまう。まず 1 つのエージェント・1 つのマップで 20 キル分メモする
2. `valoclip` でキルの場面を切り出し、`notes.md` を埋める(Claude に頼む)
3. 20 キル分たまったら、よく出る勝ち方を 3 つにまとめる
4. 別のエージェントでも同じことをする。**エージェントが変わっても出てくる勝ち方が、meiy 本人の強さの中心**。自分がどのデュエリストを使うときにも持ち込める
5. 1 つだけ課題にして、自分の試合で試す。自分のリプレイにも `valoclip` を使い、同じ項目で比べる

## 見る項目(キル 1 つごと)

| 項目 | 見るところ |
|---|---|
| 状況 | ラウンドの何秒目か / 経済 / 人数差 / 味方のスキルが入った後か |
| 位置と角度 | オフアングルか / 一度に何方向から撃たれうる場所か |
| プリエイム | 撃つ前にクロスヘアが頭の高さ・敵の出てくる位置にあったか |
| タイミング | 敵の隙(リロード・スキル直後・移動中)を狙ったか / 味方のスキルと同時か |
| 撃ち合い | 止まってから撃ったか / ピークの種類 / 何発で倒したか / 初弾がヘッドに当たったか |
| スキル | 入る前・撃ち合い中・逃げのどこで使ったか |
| キル後 | 押したか引いたか / 次の敵の方向へすぐ向いたか / トレードされない位置にいるか |

デスの場面も `--deaths` で出して、同じ項目で比べる。勝った場面と負けた場面の差が、いちばん学びになる。
