# valoclip:強いデュエリストの動画からキル場面を切り出して分析する

YouTube の URL(または手元の動画ファイル)を渡すと、次のことを自動で行います。

1. 動画をダウンロードする
2. 画面右上のキルログを見て、キルが起きた時刻をすべて拾う
3. キルごとに、キルの 4 秒前から 0.8 秒後までの 6 枚を 1 枚の画像にまとめる
4. 分析メモのテンプレート(`notes.md`)と一覧表(`kills.csv`)を作る

できた画像を Claude に渡すと、キルごとに「なぜ勝てたか」を分析し、そのプレイヤーがよく使う勝ち方をまとめられます。

## インストール(最初の 1 回だけ)

Python 3.10 以上と ffmpeg が必要です。

- Windows: `winget install Python.Python.3.12` と `winget install Gyan.FFmpeg`
- Mac: `brew install python ffmpeg`

```
git clone <このリポジトリ>
cd aaa
pip install -r requirements.txt
```

## 使い方

### 1. まず 1 本で領域を確認する(最初の 1 回)

配信の画面レイアウト(顔カメラ・枠など)によってキルログの位置が変わるため、最初に確認します。

```
python -m valoclip analyze "https://www.youtube.com/watch?v=XXXX" --section 5:00-8:00 -o valo_out
python -m valoclip calibrate valo_out/videos/XXXX_300-480.mp4 --at 1:10
```

`--at` には、キルログが出ている時刻(ダウンロードした動画の中での時刻)を指定します。`calibrate.png` を開いて確認します。

- 黄色の枠がキルログを囲んでいれば OK
- ずれていたら `--roi 0.68,0.05,0.995,0.35` のように比率(左, 上, 右, 下)を変えて、もう一度 `calibrate` を実行する
- 水色の枠は「味方がキルした行」、赤い枠は「味方が倒された行」です。行に枠が付かない場合は下の「うまく拾えないとき」を見てください

### 2. 本番

```
python -m valoclip analyze "https://www.youtube.com/watch?v=XXXX" -o valo_out --clips
```

| オプション | 意味 |
|---|---|
| `--section 12:00-40:00` | 長い配信のうち、この区間だけダウンロードして解析する |
| `--clips` | キルの 5 秒前から 2 秒後までの mp4 も書き出す |
| `--deaths` | 味方が倒された場面も出す(負け方の分析用) |
| `--times 3:12,7:45` | 自動検出を使わず、この時刻を切り出す |
| `--roi x1,y1,x2,y2` | キルログの領域(手順 1 で決めた値) |

再生リストの URL も渡せます。手元の動画ファイルも渡せます(`python -m valoclip analyze video.mp4`)。

### 3. 出力

```
valo_out/<動画ID>/
  notes.md     … キルごとの画像と分析項目。ここに書き込む
  kills.csv    … 一覧(Excel で開ける)。YouTube の該当時刻へのリンク付き
  shots/       … キルごとの 6 コマ画像
  clips/       … --clips を付けたときの mp4
```

### 4. Claude に分析してもらう

`shots/` の画像と `kills.csv` を Claude に渡して「分析して」と頼みます。渡し方は 2 通りです。

- チャットに画像を添付する(10 枚前後ずつ)
- このリポジトリに push する(`git add -f valo_out/<ID>/shots valo_out/<ID>/kills.csv`。`*.csv` は .gitignore の対象なので `-f` が必要)

## 注意(必ず読む)

- **味方全員のキルが出ます。** 視点のプレイヤーのキルだけに絞る機能はありません。`notes.md` の「本人のキル?」欄で仕分けてください。画像を見れば、撃っているのが本人かどうかはすぐ分かります
- **実際の VALORANT 動画ではまだ試していません。** 作った環境から YouTube に接続できなかったため、キルログを模した合成動画でテストしました(`tests/test_valoclip.py`)。最初の 1 本では、拾ったキルの数と実際のキルの数を見比べてください
- 動画の利用は個人の練習目的にとどめ、切り出した画像や動画を再配布しないでください

## うまく拾えないとき

| 症状 | 対処 |
|---|---|
| 行に枠が付かない | キルログの色が想定と違う(色覚設定などで変わる)。`calibrate.png` をClaude に見せれば、`valoclip/detect.py` の `ALLY_HSV` / `ENEMY_HSV_*` を合わせます |
| 同じキルが 2 回出る | 解析中に行の見た目が大きく変わっている。`detect_events` の `match_thr` を 0.10 から 0.15 くらいに上げる |
| 続けて取ったキルが 1 件にまとまる | `match_thr` を下げる(0.07 など) |
| 動画がつながらない・遅い | `--section` で区間を絞る。`--fps 3` で少し速くなる |
| 全部だめ | `--times` で時刻を手で指定する(画像化とメモ作成だけ使う) |

## 仕組み

- 1 秒に 4 枚の画像を調べ、キルログ領域で「倒した側の色(左)」と「倒された側の色(右)」を両方含む横長の帯を、キルログの 1 行とみなす
- 行の見た目(名前やエージェントアイコン)で、前の画像の行と同じ行かどうかを照合する。初めて見る行が 2 回続けて見えたら 1 キルとする。古い行が消えるのと同時に新しい行が出ても見逃さない
